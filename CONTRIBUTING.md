# Contributing to RepoPilot

Thanks for contributing.

## Development

1. Fork the repository.
2. Create a focused branch.
3. Install development dependencies with `pip install -e ".[dev]"`.
4. Run `pytest`.
5. Keep changes small and explain the motivation in the pull request.

## Safety

RepoPilot is intended to make AI-assisted development more controlled. New automation should preserve explicit approval for destructive file or shell actions.
